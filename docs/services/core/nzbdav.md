# NzbDAV has moved to InfiniDysk

NzbDAV is now **InfiniDysk**. The project repository, service name, and fresh
DUMB defaults have moved to
[`infinidysk/infinidysk`](https://github.com/infinidysk/infinidysk).

Use the [current InfiniDysk service guide](infinidysk.md) for installation,
configuration, troubleshooting, and the complete opt-in migration workflow.
Existing DUMB installations continue to support legacy NzbDAV keys, paths, and
environment variables until their operator chooses a migration path.

[Open the InfiniDysk migration guide](infinidysk.md#migration-from-nzbdav){ .md-button .md-button--primary }
